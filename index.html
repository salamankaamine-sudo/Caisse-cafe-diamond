❓ دليل الاستخدام السريع

1. إضافة دواء: صفحة "الأدوية" → زر "+ إضافة"، املأ الاسم/السعر/الفئة/الصلاحية ثم احفظ.

2. إجراء بيع: صفحة "نقطة البيع" → اختر الأدوية لإضافتها للسلة → اختر الزبون (اختياري) → "إتمام البيع".

3. طباعة فاتورة: تتم تلقائياً بعد كل بيع، أو من "أرشيف المبيعات" → زر الطباعة.

4. إدارة الديون: صفحة "سداد الديون" → اختر الزبون → أدخل المبلغ المسدد.

5. تغيير PIN: صفحة "الإعدادات" → بطاقة "تغيير PIN".

6. تصدير التقارير: صفحة "التقارير" أو "أرشيف المبيعات" → زر "📄 تصدير PDF" أو "📊 تصدير Excel".
